# 操作员工作流复核

> 复核日期：2026-09-30
> 范围：本仓库 Wails 客户端及当前 Sliver Go 依赖；不包含 Teamserver 部署与服务器运维

## 复核结论

开发计划中的主要操作流程均已有可发现的中文入口，并由 Wails 绑定调用当前 Sliver 客户端 API。实时 Session 与异步 Beacon、客户端本地辅助与 Teamserver RPC、自动验证与需要真实测试环境的步骤均已区分。

“工作流完成”表示客户端入口、参数、状态、错误和能力边界已经落地，不表示所有 Teamserver 版本或所有目标平台都能提供相同能力。连接后仍以兼容性中心和 RPC 实际返回为准。

| 工作流 | 可发现入口 | 后端能力 | 状态与边界 | 验证证据 |
|---|---|---|---|---|

## 自动与人工验证边界

仓库自动验证运行 `scripts/verify.ps1`，覆盖 Go 单元测试与静态分析、前端 JavaScript 语法和测试，以及 Wails 绑定清单生成。计划状态和文档边界另行通过差异审阅与未完成标记扫描核对。验证不会连接 Teamserver，也不会在远程目标执行命令、启动监听或建立隧道。

需要真实授权测试环境的项目保留在 `docs/TESTING_AND_SUPPORT.zh-CN.md` 的人工冒烟清单中。未执行某一真实环境冒烟不代表客户端代码入口缺失；发布候选版本仍应按该清单完成目标版本和平台验证。

## 明确边界

- CDN 或反向代理后的原始公网 IP 只有在代理链和 Teamserver 保存并通过 RPC 暴露时才能展示，GUI 不能从主机网卡地址反推。
- Teamserver 安装、服务管理、环境变量、防火墙和文件系统不属于本客户端的隐式管理范围。
- 官网中的原理、安装、编译、第三方工具和服务器运行模式主题以文档或兼容性提示呈现，不伪装成按钮功能。
- 上游没有稳定 RPC、当前依赖没有实现或仅属于特定构建格式的能力，会明确显示为受上游限制或专用流程。
