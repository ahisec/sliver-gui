# 测试与支持基线

## 自动验证

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify.ps1
```

该命令只执行本地静态检查、单元测试和绑定清单生成，不连接 Teamserver。

## 人工冒烟清单

使用专门的已授权测试 Teamserver 和不含生产凭据的操作员配置执行：

- [ ] 登录页点击“添加操作员配置”，打开后取消 Windows 原生文件选择器，桌面进程保持运行。
- [ ] 导入无效 `.cfg`，显示中文校验错误且不泄露 Token、私钥或完整配置。
- [ ] 使用有效 `.cfg` 连接，版本、操作员、Session/Beacon 和兼容性快照正常加载。
- [ ] 主动断开后回到登录页；网络中断时显示重连状态，取消重连可用。
- [ ] 对测试 Beacon 提交无害命令，任务中心显示排队、等待和最终状态。
- [ ] 对仍排队的测试 Beacon 任务执行取消，Teamserver 状态与客户端状态一致。
- [ ] 打开 Session 的文件与进程面板，加载态、空态和错误态均不会卡死主界面。
- [ ] 新建植入体档案后重新载入并覆盖保存，通用字段、多个 C2、HTTP C2 档案和 WireGuard 专用字段均能正确回填。
- [ ] C2 包含 HTTP(S) 时 HTTP C2 档案下拉及查看、创建、导入、编辑、验证入口可用；移除 HTTP(S) 后字段自动禁用且不提交旧值。
- [ ] C2 包含 `wg://` 或 `wireguard://` 时 WireGuard 隧道 IP 和端口可编辑；移除 WireGuard 后字段自动禁用且不提交旧值。
- [ ] 在 720px 窄窗口检查档案、构建记录、活动监听器、脚本管理器和 HTTP C2 编辑器，无不可达控件或依赖大范围横向拖动的内容。
- [ ] 按 `docs/OPERATOR_WORKFLOW_REVIEW.zh-CN.md` 逐项检查连接、监听、生成、目标、文件、进程、网络、扩展、MCP、审计和报告入口。

## 支持范围

| 项目 | 支持基线 | 说明 |
|---|---|---|
| Windows | Windows 10 22H2、Windows 11 23H2 及更新版本 | 主要开发与原生对话框回归平台，使用 WebView2 |
| Linux | 当前受 Wails 2.16 支持的主流 x86_64 桌面发行版 | 需系统 WebKitGTK；发布前在目标发行版验证 |
| macOS | macOS 13 及更新版本，Intel/Apple Silicon | 使用 WKWebView；应用内确认框不依赖浏览器原生对话框 |
| Teamserver | 与 `go.mod` 中 Sliver 客户端依赖兼容的 1.7 开发线 | 当前依赖提交为 `e53f66de72b9`；连接后以兼容性中心的实际探测为准 |

未列出的旧系统和不同主版本 Teamserver 属于尽力兼容范围。功能是否可用以连接后的能力探测为准，不以版本字符串单独推断。

## 新增界面验收

- [ ] 所有面向用户的标题、按钮、提示和错误默认使用中文。
- [ ] 加载中有明确状态，空结果不是空白页面，失败可查看安全过滤后的说明。
- [ ] 只有真实后端能力才显示取消；重试不会重复提交不可幂等操作。
- [ ] 任何 Token、密码、私钥、C2 URL 和命令正文不进入普通任务摘要或审计详情。
- [ ] 720px 窄窗口与常规桌面窗口无重叠、截断或不可达操作。
- [ ] 删除、终止、覆盖等危险操作包含目标摘要和应用内二次确认。
- [ ] 原生打开/保存对话框取消后应用继续响应。
- [ ] 新 Go 逻辑有聚焦测试，所有前端 JavaScript 通过语法检查。
